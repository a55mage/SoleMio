# Sole Mio - Weather App

## Features
- Real-time weather search by city name or coordinates
- Current location weather detection
- Current weather display (temperature, conditions, wind, humidity)
- 7-day weather forecast
- Wind direction with cardinal points (N, NE, SW, etc.)
- Precipitation probability

## Technologies
- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
- Open-Meteo API
- Open-Meteo Geocoding API

## Browser Support
Requires modern browsers with support for:
- Geolocation API
- Fetch API
- ES6+ JavaScript
